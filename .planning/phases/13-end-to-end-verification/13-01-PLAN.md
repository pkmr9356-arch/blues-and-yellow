# Phase 13 Plan: Final End-to-End Verification, Performance & Responsive QA

## Goal
Perform comprehensive end-to-end functional verification, multi-viewport responsive testing (390px, 768px, 1440px), accessibility and contrast audits, production build checks, and an honest content/claim review across all 21 routes.

## Tasks

1. **All 21 Routes Functional & Status Testing**:
   - Start the production Next.js build on a dedicated local port.
   - Test all 21 static and dynamic routes via automated HTTP/DOM requests:
     - Core: `/`, `/about`, `/contact`, `/start-a-project`, `/privacy-policy`, `/terms`
     - Services: `/services`, `/services/website-development`, `/services/web-applications`, `/services/wordpress-development`, `/services/mobile-app-development`, `/services/seo`, `/services/digital-strategy`, `/services/maintenance`
     - Portfolio: `/work`, `/work/project-alpha`, `/work/project-beta`, `/work/project-gamma`
     - Insights: `/insights`, `/insights/scalable-web-apps`, `/insights/seo-best-practices`, `/insights/design-systems-scale`
     - Admin: `/admin/login`, `/admin`, `/admin/leads`
   - Validate HTTP status codes (200 OK for public, 307/308 redirect to `/admin/login` for unauthenticated admin routes).

2. **Security & Form Interaction Verification**:
   - Test `src/proxy.ts` unauthenticated route guard against `/admin` and `/admin/leads`.
   - Verify `ProjectInquiryForm` client and Server Action validation:
     - Bot honeypot filter blocks spam silently without dispatching email.
     - Empty/invalid field submissions return proper error messages without crashing.
   - Verify that no unauthorized access or unvalidated data bypasses the proxy.

3. **Multi-Viewport Responsive & Motion QA**:
   - Run taste-skill headless Chromium CDP inspector at 390px (mobile), 768px (tablet), and 1440px (desktop).
   - Inspect key representative templates:
     - Homepage with editorial hero, inline media aperture, and protected GSAP horizontal scroll.
     - Capability detail page (`/services/website-development`).
     - Case study page (`/work/project-alpha`).
     - Insights article page (`/insights/scalable-web-apps`).
     - Forms & intake (`/contact`).
     - Site-wide footer navigation and media attributions.
   - Verify horizontal overflow, keyboard focus visibility, and reduced-motion fallback.

4. **Performance, Lint, & Build Gates**:
   - Execute `npm run lint` and verify exit code 0.
   - Execute `npm run build` and verify exit code 0.
   - Verify local font asset loading (Inter and Erode WOFF2) without external runtime font layout shifts.

5. **Content Claims & Demonstration Audit**:
   - Audit all case-study claims and demonstration badges in `src/app/work/[slug]/page.tsx`.
   - Clearly document demo architecture content vs verified production client deliverables.
