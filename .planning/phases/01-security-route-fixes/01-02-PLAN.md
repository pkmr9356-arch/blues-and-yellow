### Task 3: Server Action Zod Validation & Anti-Abuse Throttling
- **Files**: `src/app/actions/submit-inquiry.ts`
- **Action**:
  1. Import `z` from `zod` in `src/app/actions/submit-inquiry.ts`.
  2. Define validation schema:
     ```typescript
     const inquirySchema = z.object({
       name: z.string().trim().min(2, 'Name must be at least 2 characters').max(100, 'Name must not exceed 100 characters'),
       email: z.string().trim().email('Please enter a valid email address').max(255),
       message: z.string().trim().min(10, 'Project summary must be at least 10 characters').max(5000, 'Project summary must not exceed 5000 characters'),
       bot_field: z.string().max(0, 'Spam detected').optional(),
     });
     ```
  3. Extract fields from `FormData` and validate with `inquirySchema.safeParse(...)`.
  4. If validation fails, return `{ success: false, error: parsed.error.issues[0].message }` immediately without touching Supabase or Resend.
  5. Add basic rate limiting guard (e.g. check timestamp cookie or in-memory window allowing at most 3 submissions per IP per 5 minutes) to protect Resend sending quotas.
  6. For valid submissions, insert sanitized data into Supabase `leads` table and dispatch the existing Resend notification email to `hello@bluesandyellow.agency`.
- **Verification**:
  - Submit an inquiry with name `"A"`; verify server action returns `{ success: false, error: "Name must be at least 2 characters" }` and nothing is inserted into Supabase.
  - Submit an inquiry with invalid email `"john@notanemail"`; verify server action returns `{ success: false, error: "Please enter a valid email address" }`.
  - Submit a valid payload; verify `{ success: true }` is returned, lead row appears in Supabase, and Resend delivery is invoked.
- **Regression Check**:
  - Test `/start-a-project` client form with valid submission; verify the green "Thank you!" success panel appears as normal.

## Threat Model & Acceptance Criteria
- **Threat (T-01-02)**: Automated script spams `/actions/submit-inquiry` with empty or giant payloads, polluting database and draining Resend email quotas.
  - *Mitigation*: Zod validates string length limits and email syntax; bot honeypot and throttling intercept rapid spam before DB/API calls.
- **Acceptance Criteria**:
  - Next.js 16 dynamic pages render with 0 async params warnings.
  - `/services/wordpress-development` returns HTTP 200 with branded content.
  - Invalid inquiry submissions return clear error messages and never trigger Resend emails.
  - Valid inquiry submissions succeed and notify `hello@bluesandyellow.agency`.
