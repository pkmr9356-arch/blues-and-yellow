# Phase 11 Plan: Site-Wide Editorial Redesign & Slop Elimination

## Goal
Elevate the editorial craftsmanship, typographic hierarchy, visual storytelling, and consistency across all key public routes (`/about`, `/services` and its subpages, `/work` and case studies, `/insights` and articles, and `/contact`) while eliminating generic agency templates, rest shadows, and unstyled headers.

## Tasks

1. **Elevate `/about` Page**:
   - Transform `src/app/about/page.tsx` with editorial display serif headline (`font-serif` Erode).
   - Add rich studio narrative on balancing visual design with technical discipline.
   - Include authentic studio imagery (`frederick-osterling-architectural-studio-2015-06-17.jpg` or `view-from-photographer-s-studio.jpg`) with proper credits.
   - Structure Core Engineering Principles (Type-Safe Foundations, Sub-Second Performance, Fail-Closed Security, Universal Accessibility).
   - Polish 3-stage delivery process and add prominent dual CTA closure.

2. **Elevate `/services` Directory & Service Subpages**:

     - Add back-navigation breadcrumbs (`← Back to all services`).
     - Align headings to `font-serif` Erode.
     - Elevate deliverables into structured tone cards.
     - Add dual action buttons ("Request a Proposal" and "Explore Case Studies").

3. **Elevate `/work` Showcase & Dynamic Case Studies**:

   - Enhance `src/app/work/[slug]/page.tsx` with structured challenge, approach, solution, and outcomes cards, plus clear conversion links.

4. **Elevate `/insights` & Article Detail Pages**:
   - Refine `src/app/insights/page.tsx` and `src/app/insights/[slug]/page.tsx` with clear reading typography, publication metadata, and architectural callout panels.

5. **Harmonize `/contact` and `/start-a-project`**:

6. **Verification & Multi-Viewport Inspection**:
   - Run `npm run lint` and `npm run build` to confirm 0 errors/warnings.
   - Inspect key pages across 1440px, 768px, and 390px viewports.
